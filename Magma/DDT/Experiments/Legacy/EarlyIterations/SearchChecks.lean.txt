/-!
# Reproducible search observations

Build this module explicitly with `lake build Magma.Evidence.SearchChecks`.
It is not imported by `Magma`, so the longer research checks do not run in
the normal build. Lake caches the compiled module; changes to this source,
its imports or build settings cause the checks to run again.

Every `#guard_msgs` snapshot is the expected output of the following `#eval`.
Compilation fails if the observed output differs. These are checks on fixed
inputs, not universal correctness or performance claims. Historical timing
transcripts remain next to the profilers in `Magma.FastSearch` and
`Magma.Evidence.ThreeRoundImpossible`.
-/
